# Taskpad — AI-Built To-Do & Notes App

Taskpad is a clean, responsive, client-side To-Do List application featuring dynamic task notes, priority management, and task progress tracking. Built entirely using AI guidance as part of the HNG Internship 15 (Stage 1).


## ✨ Features

- **Core Task Management:** Create, view, mark complete, edit, and delete tasks.
- **Contextual Notes:** Toggle collapsible notes on any task for extra context or sub-details.
- **Priority & Due Dates:** Assign Low, Medium, or High priority levels alongside due date tracking with automatic overdue visual indicators.
- **Search & Filtering:** Real-time search across task titles and note contents, with quick filters for *All*, *To Do*, and *Done*.
- **Progress Metrics:** Visual progress bar and dynamic counter summarizing completed vs. active tasks.
- **Local Persistence:** Data persists in the user's browser using `localStorage`.


## 🛠️ Tech Stack

- **HTML5:** Semantic markup & accessibility standard 
- **CSS3:** Custom CSS variables, flexbox/grid layouts, responsive styling, and native dark mode support
- **JavaScript (ES6+):** Pure vanilla JavaScript DOM manipulation and `localStorage` integration
